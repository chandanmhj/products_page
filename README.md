# products.chandanmhj.in

React + three.js products page. Add a product by editing `src/products.js`.

- Run locally: `npm install` then `npm run dev`
- Build: `npm run build` (output in `dist/`)
- Deploy: Netlify, build command `npm run build`, publish directory `dist`
- When you add a product, also add it to the JSON-LD block in `index.html` for SEO
